# Kangaroos CMS – Test

Minimales Skelett zum Ausprobieren von [Pages CMS](https://pagescms.org).

- `.pages.yml` – Konfiguration für Pages CMS
- `content/test.md` – einzelne Testseite (Typ `file`)
- `content/news/` – Collection für News-Beiträge (neue Einträge anlegen, bearbeiten, löschen)
- `public/images/` – Ablage für hochgeladene Bilder

Zum Testen: Repo in app.pagescms.org öffnen (GitHub App installieren) und loslegen.
